## Current primary-source roles and limits

1. [New Mexico OCD statistics](https://www.emnrd.nm.gov/ocd/ocd-data/statistics/), checked 2026-09-25, labels C-115 reported production data as updated nightly with a 45-day lag and links a **Well Search by API** route. It also lists separate operator, county and statewide production summaries. Those broader summaries are not substitutes for the exact well/API retrieval.
2. The current [OCD C-115 instructions](https://www.emnrd.nm.gov/ocd/wp-content/uploads/sites/6/C115-INSTRUCTIONS.pdf), “Verification of data submitted — Well Search Tool” section, describe OCD Permitting → Searches → Wells → API number → Production quick link, year expansion to months, and Excel export. They identify the displayed data as production/injection totals submitted on C-115 by API number. The same manual says approved reports and amendments update overnight; the next business day may be needed after approval. Its audience is operators, so a public article should verify the present read-only interface before stating that an owner can follow every operator-facing step unchanged.
3. [OCD Permitting](https://www.emnrd.nm.gov/ocd/ocd-e-permitting/) identifies C-115 as the operator's monthly report and links official instructions. The page returned HTTP 200 in a direct CLI check on 2026-09-25, but no current interactive Well Search walkthrough was completed; do not represent this as one. Obtain a stable read-only route before public admission.
4. [OCD's mission page](https://www.emnrd.nm.gov/ocd/) describes well-production data collection and oil-and-gas regulation. This establishes the public data's regulator role, not an owner-level payment or private-title determination.

The official sources do **not** identify a particular owner's well, tract coverage, title, decimal, lease terms, payor price, deductions, or net payment. Do not infer those from a public API hit, a `Mineral Owner` field that denotes a category, a nearby map point, or a 45-day delay. The OCD statistics page and the well-detail UI may display different refresh notes; state the source-specific label and access date rather than forcing one universal update schedule.

## Candidate answer contract

Lead with the practical route: obtain the exact API number and production month from the statement or ask the payor for its cross-reference; use OCD's official Well Search to retrieve that API's production section, expand the relevant year/month, save the source URL/export and access date, then compare **identifier, product and production period** with the private statement. If the public row is missing or differs, preserve the search input and ask the payor which well/property and accounting period its payment uses. The public C-115 total is not an owner payment ledger. Separate production, sales/payment dates and later amendments; avoid a numeric royalty formula, asserted shortage, or claim that OCD settles private payment disputes.

Potential structure: direct answer; exact API and month precondition; current OCD source route; lag/amendment caveat; a short mismatch register; what the source cannot establish; privacy-aware next step under the royalty pillar.
