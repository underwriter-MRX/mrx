> **Identifier crosswalk, not a property-match conclusion.** This page explains source-owned labels in Texas mineral records. It does not identify an owner, legal description, tract, unit, lease effect, royalty decimal, payment right, appraisal result, tax amount, production result, private value, offer, buyer action, or transaction outcome. MRX may have an economic interest in a later mineral transaction. When that applies, the buyer relationship is disclosed in writing before an agreement is signed.

The direct answer is: **a CAD account number, an RRC API number, an RRC lease or gas-well identifier, and an RRC operator number belong to different record systems and answer different identity questions**. Keep each value in its own field with the agency, exact source label, oil-or-gas context, district where shown, and retrieval date.

Do not turn one of these numbers into a universal property key. A similar number, lease name, operator name, county, or field can guide a controlled follow-up search, but it does not prove that two records describe the same private mineral interest.

## The identifier crosswalk

| Identifier lane | Source-owned role | Fields to preserve beside it | What it does not prove |
| -- | -- | -- | -- |
| CAD long account number | Appraisal district's long or geographic property code | District, exact field label, legal-description reference, tax year, retrieval date | Title, mineral ownership, account correctness, or private value |
| CAD short account or R-number | Appraisal district's shorter local property code | Long account number when shown, district, exact format, retrieval date | That it equals a GIS ID, RRC number, or another district's format |
| RRC API number | Regulatory wellbore identifier | County, district, well label, source route, retrieval date | Tract inclusion, lease effect, royalty entitlement, production, or value |
| RRC district plus oil lease number or gas-well ID | Regulatory completion or production-lane identifier | Oil-or-gas label, district, lease or well name, operator label, period | Private lease interpretation, owner participation, decimal, or payment |
| RRC P-5 operator number | Regulatory organization identifier | Operator name as displayed, status context, source route, retrieval date | Mineral ownership, authority for a private party, payee identity, or buyer qualification |

The safest reusable row also includes **source object**, **copied by**, **copied at**, **format preserved**, **connection evidence**, and **question not answered**. If the issuer or field label is unclear, stop before making a join.

## CAD long account, short account, and GIS ID are separate fields

The current [Texas Comptroller Electronic Appraisal Roll Submission manual](https://comptroller.texas.gov/taxes/property-tax/docs/96-1051.pdf) defines its account-number field as the unique long code an appraisal district uses to identify a specific property. It notes that geographic account number and Geo ID can be other names for that long code. The manual separately defines the short account number as a unique short code that may also be called a parcel number or R-number.

The same manual has a separate GIS parcel ID field and says that value may or may not match the account or short account number. That is a useful stop condition: do not assume every local property identifier is an alias merely because the values appear on one screen.

The current [Electronic Property Transaction Submission manual](https://comptroller.texas.gov/taxes/property-tax/docs/96-1208.pdf) likewise calls the short account number a locally assigned shortened account or R-number. It says a separate record should be submitted for each account when a transaction includes more than one account. This article uses that statement only as support for preserving separate rows. It does not interpret a transaction or deed.

Use this CAD capture pattern:

- copy the district name and exact page, file, or report title;
- copy the label exactly: long account, geographic account, Geo ID, short account, parcel number, R-number, or GIS parcel ID;
- preserve leading characters and punctuation exactly as shown;
- record the tax year or source period separately from the retrieval date; and
- write `not shown` instead of manufacturing an alias or cross-system match.

## API number identifies the wellbore lane

The [Texas RRC About Oil and Gas Data Queries page](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) says a wellbore is assigned a number referred to as the API number. It also says a wellbore may contain one or more completions or may be a dry hole.

That distinction matters when a family packet contains an API number and a lease number. The API value identifies the wellbore in the Commission's regulatory system. It does not, by itself, say that a particular mineral owner participates in the well, that a deed covers the tract or depths, that a royalty decimal is correct, or that production belongs to a private account.

Use [Texas RRC Wellbore Query Retrieval-Provenance Worksheet](/blog/texas-rrc-wellbore-query-retrieval-provenance-worksheet/) for the query-specific retrieval path. Article 298 owns only the cross-system identifier labels and does not repeat the query controls or result-field inventory.

## District plus lease number or gas-well ID identifies a different RRC lane

The same RRC query guide says each completion is identified by a district number and an oil lease number or gas-well ID number. Preserve all three parts of that statement:

1. whether the record is in the oil-lease or gas-well lane;
2. the RRC district; and
3. the oil lease number or gas-well ID exactly as displayed.

Dropping the district or oil-or-gas context can make a copied number look more universal than the source says it is. A lease name is also not a substitute for the numbered field. Names can resemble one another, change, or appear differently across records.

The [RRC Oil Leases and Gas Wells by District and Operator index](https://www.rrc.texas.gov/oil-and-gas/research-and-statistics/well-information/oil-leases-and-gas-wells-by-district-and-operator/) is organized by district, operator name, and lease name. The current page says the monthly index includes operator number, lease number, field number and name, county number and name, and an oil-or-gas label. Co-display helps preserve context; it does not make those fields interchangeable.

The [RRC Production Data Query System FAQ](https://www.rrc.texas.gov/about-us/faqs/oil-gas-faq/production-data-query-system-faqs/) provides one bounded bridge. It says an API number can be entered in the Wellbore Query to obtain lease information, including a lease number, and that the lease number can then be used to access PDQ. That is a documented lookup sequence, not proof of a private-property connection. The FAQ also describes PDQ as a monthly, revisable snapshot.

## P-5 number identifies the operator lane

The RRC query guide says a regulated company files an Organization Report, Form P-5, and that the Commission issues a P-5 number unique to that operator. Preserve the displayed operator name, number, status context, exact source, and retrieval date together.

An operator number is not an owner number. It does not identify the mineral owner, royalty payee, purchaser, title holder, private contract party, or qualified buyer. An operator name appearing beside a lease or well record does not establish the operator's authority for a private person or prove that the record applies to the interest being reviewed.

For time-separated operator evidence, use [Mineral Rights Operator Name Change Log](/blog/mineral-rights-operator-name-change-log/). That page owns historical name transitions. This page owns only the identifier type and source label.

## Copy identifiers as shown without publishing private values

A reusable public template should remain blank. Keep real account numbers, API numbers, lease or gas-well IDs, operator numbers, owner names, addresses, legal descriptions, coordinates, payment details, and private documents in an authorized controlled location.

For each controlled row, preserve:

| Packet field | Entry rule | Stop condition |
| -- | -- | -- |
| Source owner | Texas Comptroller, appraisal district, Texas RRC, or another named issuer | Stop if the issuer is unclear |
| Exact source object | Page title, PDF name, query route, report, or retained file | Do not cite an informal screenshot label as the source |
| Identifier label | Copy the field name exactly as displayed | Do not rewrite a short account as an RRC lease ID |
| Controlled value reference | Point to the authorized record without exposing the value publicly | Do not place real identifiers in a reusable example |
| Companion fields | District, oil-or-gas label, long/short form, operator label, period, or status when shown | Do not detach a number from source-owned context |
| Retrieval provenance | Date, time, timezone, URL, file hash, or controlled capture reference | Do not call retrieval time the source's effective period |
| Connection evidence | Separate deed, owner, tract, unit, payor, or title evidence when actually available | A matching number or name is not connection evidence by itself |
| Limitation | State the question the source does not answer | Stop before extending the record beyond its lane |

For a dedicated production-search index, use [How to Build a Texas Mineral Production Record Locator Sheet](/blog/how-to-build-a-texas-mineral-production-record-locator-sheet/). It owns the production-locator job; this article does not reproduce it.

## What these identifiers do not establish

No identifier in this crosswalk independently proves:

- legal title, mineral ownership, authority, or the right to act;
- a legal description, tract, depth, unit, or private lease connection;
- that a CAD account is correct, current, or limited to a mineral interest;
- that an owner participates in a well or production record;
- a royalty decimal, payor obligation, payment amount, or entitlement;
- production completeness, engineering conclusions, reserves, or future activity;
- an appraisal result, tax result, private value, fair offer, or transaction outcome; or
- that two records describe the same property because their names or numbers resemble one another.

Those conclusions require their own responsible sources and qualified review. An identifier improves retrieval and provenance; it does not expand what a record proves.

Before joining records for an owner-specific decision, verify the source object, exact identifier label and format, district, oil-or-gas lane, period, version, operator context, legal description, tract or unit evidence, ownership documents, and purpose.
