## Preserve the publisher-to-file chain

Start at the [Ector County Appraisal District home page](https://www.ectorcad.org/). During the recorded review, its public resource list displayed a `Reappraisal Plan` link. Preserve that publisher surface before opening the file.

Preserve the [exact linked reappraisal-plan PDF](https://www.ectorcad.org/pdf/reappraisal_plan.pdf) as a second evidence object. The home page supplies the publisher relationship. The PDF supplies the displayed document identity, page count, and page-level observations. A downloaded file without the current home-page relationship does not by itself show what the district currently links.

One complete-file retrieval on 2026-08-28 returned HTTP 200 as `application/pdf`, contained 1,901,263 bytes and 120 physical pages, supplied `Last-Modified: Wed, 05 Aug 2026 20:56:20 GMT`, and matched SHA-256 `ee9903cd6741dc132fc80688c84b39e98e561ef808d65f96f45e912853f6149a`. Those facts identify one retrieved source state. A later file with different bytes, pages, dates, or headings must be recorded separately.
