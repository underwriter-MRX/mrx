> **Official-file integrity boundary.** This page records one Howard CAD publisher route, one complete 2025 ZIP retrieval, one central-directory inventory, and one container integrity result. It does not open or read the XLSX member; reproduce a row or cell; query a person, property, account, operator, lease, or owner; establish ownership, title, acreage, royalty, appraisal, tax, mineral-rights sale value, offer quality, or legal effect; or recommend a transaction. MRX may have an economic interest in a later mineral transaction. When that applies, the buyer relationship is disclosed in writing before an agreement is signed.

The official [Howard CAD downloads page](https://howardcad.org/downloads/) supplied a precise answer on 2026-08-29: **its `2025 Certified Mineral Roll` label linked to a 25,248,834-byte ZIP whose SHA-256 was `6689f36042fae4befed0175ffa240cbb997081cdbd445e7654f3a4d5f42ca141`. The ZIP central directory contained exactly one unencrypted XLSX member, and `unzip -t` passed.**

That result identifies the retrieved container and its stored member metadata. It does not show what any workbook row says, whether the file is complete or current for a later date, who owns an interest, what a property is appraised for, what tax is due, what mineral rights could sell for, or what an owner should do.

## Keep the publisher page and file route together

The [Howard Central Appraisal District homepage](https://howardcad.org/) identifies the publisher. The downloads page then supplies the relationship between a visible link label and the exact file URL.

| Source object              | Recorded role                                      | What it does not prove                                               |
| -------------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| Howard CAD homepage        | Publisher and site context                         | File contents, property facts, ownership, title, value, or tax       |
| Howard CAD downloads page  | Visible link labels and destination URLs           | That every linked file has the same year, format, scope, or contents |
| Exact 2025 ZIP             | Complete retrieved container bytes                 | Workbook accuracy, completeness, row meaning, or legal effect        |
| Howard CAD property search | Separate research interface and disclaimer context | A result for any person or property; no query was performed          |

Preserve both the page URL and the final ZIP URL. A copied file URL without its publisher page loses the visible label and surrounding year context. A copied label without the exact file URL loses the identity of the retrieved bytes.

## Keep the three byte counts distinct

This record contains three different size numbers:

1. **25,248,834 bytes** is the complete ZIP container returned by the server.
2. **25,248,554 bytes** is the compressed size stored for the one XLSX member.
3. **25,562,263 bytes** is the member's uncompressed size recorded in the central directory.

The numbers should not be substituted for one another. The complete ZIP includes container structure in addition to the compressed member. The uncompressed size is metadata for the member after decompression, not the number of records or cells.

## Distinguish SHA-256, CRC, and the integrity test

The complete-file SHA-256, member CRC, and passing `unzip -t` result answer different questions.

| Check      | Narrow question answered                                                      | Boundary                                                                                   |
| ---------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| SHA-256    | Are these complete ZIP bytes identical to the recorded retrieval?             | Does not assess meaning or correctness                                                     |
| Member CRC | Does the decompressed member match the CRC stored in this ZIP?                | Does not authenticate the publisher or validate workbook content                           |
| `unzip -t` | Can the tool read the archive structure and test the member without an error? | Does not prove completeness, accuracy, privacy, ownership, title, appraisal, tax, or value |

Calling the ZIP `valid` without naming the check would be too broad. The bounded statement is that this retrieval passed the recorded ZIP integrity test.

## Do not mix the 2025 and 2026 links

On 2026-08-29, the downloads page listed a separate `2026 Certified Mineral Roll` above the 2025 link. It also listed a separate 2025 real-property roll PDF. Article 261 does not inspect either file.

Year, label, destination, format, byte size, and hash belong to the exact linked object. A newer page entry does not silently update the 2025 ZIP, and the 2025 real-property PDF is not the 2025 mineral dataset ZIP.
