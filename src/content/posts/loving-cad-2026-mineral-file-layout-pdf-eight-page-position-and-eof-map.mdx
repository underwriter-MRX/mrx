## Preserve the SITUS and EOF mismatch

The source does not present one internally identical endpoint summary.

- Physical page 8 visibly starts the SITUS street-number row at `2201`.
- Physical page 8 displays the EOF row at `2260`.

This page records both physical displays. It does not move the page-8 start to 2202, move its EOF to 2261, or choose the detailed table over the summary. A source-preserving worksheet can add a separate analyst note, but that note should never replace either displayed boundary.

Keep at least five fields separate:

1. physical page number;
2. source section, such as summary or detailed table;
3. exact displayed start position;
4. exact displayed end position;

That separation prevents a later spreadsheet, parser, or summary from silently turning two different source statements into one unsupported answer.
