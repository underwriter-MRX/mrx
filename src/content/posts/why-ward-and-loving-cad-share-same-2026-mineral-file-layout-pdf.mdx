The direct answer is: **the Ward and Loving CAD 2026 archives retrieved August 31, 2026 contain byte-identical copies of `2. MINERAL FILE LAYOUT.pdf`.** Each selected member is 46,370 bytes and has SHA-256 `f0b34cc4b7a96e6cd5480f350f28554b3af72fc9cfd45959763f76d0aef1b020`.

## What the matching hash does not answer

A byte-identical file can appear in two publisher-controlled archives without the file itself revealing the publication history. The matching hash does not answer:

1. who authored the layout;
2. which district, vendor, or system originated it;
3. how or when each publisher received it;
4. whether both districts intended the same use;
5. whether the file is current for either archive;
6. whether either TXT or CSV export conforms to it;
7. whether any field label, record, or interpretation is accurate.

Those are separate claims requiring separate evidence. The careful answer is not that one district copied another, that a common vendor authored the file, or that the layout must apply everywhere. None of those explanations is established by the reviewed sources.
